# 簡報・圖文款（每頁配圖）

## 什麼時候用
使用者要比較活潑、好懂的簡報，例如新人介紹、活動說明、給客戶看的提案。

## 怎麼做
1. 問主題、給誰看、大約幾頁（沒說就做 5 頁），先列大綱：每頁一個標題、兩三個重點、一句「這頁要配什麼圖」。使用者說好再做。
2. 配圖，兩種方式選一種，並告訴使用者你用哪一種：
   - 你有生圖工具：每頁生一張，同一份簡報用同一種畫風（例如溫暖的扁平插畫），圖裡不要放字。
   - 沒有生圖工具：用 SVG 程式碼自己畫簡單的插圖（圖示、人物剪影、圖表），畫風一致、顏色跟簡報配色一樣。
3. 做成一個 index.html，圖片放在同一個資料夾：
   - 左圖右文或上圖下文交錯；字比圖少；配色最多三個顏色。
   - 鍵盤 ←、→ 換頁，手機可以左右滑，右下角頁碼。
4. 有 GitHub 小幫手（github-helper）就放上網給公開網址；沒有就把整個資料夾壓縮傳給使用者。

## 做完要長怎樣
- 每一頁都有一張跟內容有關的圖，整份畫風一致。
- 圖不會把字擋住，手機打開也看得清楚。

## 安全規則
- 不畫真實人物的臉、不放公司或品牌 logo，除非使用者提供而且是自己公司的。
- 放上網就是公開：客戶資料、個資、金鑰一律不放。
