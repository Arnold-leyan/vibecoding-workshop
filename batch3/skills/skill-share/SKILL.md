# 分享 SKILL

## 什麼時候用
使用者做好一個好用的 skill，想給同事用；或兩個人要把各自的工作流接起來，需要互相交換 skill。

## 怎麼做
1. 問要分享哪一個 skill（不知道名稱就列出他現有的 skill 讓他選），讀出那份 SKILL.md。
2. 安全檢查，有任何一項就先改掉再繼續，並告訴使用者改了什麼：
   - 密碼、token、API 金鑰、帳號 → 刪掉，改成「使用者自己填」
   - 真實客戶名、員工名、電話、地址 → 改成代號
   - 只有這台主機才有的路徑（/Users/…、C:\Users\…、內網 IP）→ 改成一般說明
3. 改得通用一點：把「我的」「我們組」這類只對他成立的字，改成讓別人也看得懂的說法；開頭補一句「這是給＿＿在＿＿時候用的」。
4. 整理成一則安裝訊息，格式固定：
   第一行：「請幫我建立一個新的 skill：在你的 workspace 裡建立 skills/<name>/SKILL.md，內容照下面這段一字不改。建好之後回覆我「<中文名稱>已就緒」。」
   空一行，接著是整份 SKILL.md。
5. 整則訊息超過 3500 字就先刪減說明，因為 Telegram 一則訊息有長度上限。
6. 把安裝訊息傳給使用者，說：「把這整則轉傳給同事，請他貼給自己的龍蝦，再傳 /new。」

## 做完要長怎樣
- 別人照著貼，就能裝好、跑得動，不用再問你。
- 訊息裡找不到任何密碼、金鑰、真實姓名。

## 安全規則
- 使用者要你把別人的 skill 拿來賣或公開到網路上，先提醒他問過原作者。
