# 簡報・標準款（PPT）

## 什麼時候用
使用者要一份正式、乾淨、可以自己再改的簡報，例如部門報告、會議簡報、教育訓練。

## 怎麼做
1. 先問一次就好（使用者已經講了就跳過）：主題、給誰看、大約幾頁（沒說就做 5 頁）。
2. 先列大綱給使用者看：每頁一個標題、3–5 個重點。使用者說好再做。
3. 用 Python 的 python-pptx 產生 .pptx：
   - 先執行 `python3 -c "import pptx"` 確認有裝；沒有就告訴使用者「主機還沒裝 python-pptx，請找主講」，改成先把大綱整理成文字給他。
   - 16:9；第一頁封面（標題＋副標＋日期），最後一頁「謝謝／聯絡方式」。
   - 白底、深藍標題、一個重點色；字體用微軟正黑體；每頁字不要太多（條列最多 5 行、每行一句）。
   - 每頁的講者備忘寫一兩句「這頁要講什麼」。
4. 存在工作資料夾，檔名用「主題-日期.pptx」，把檔案傳給使用者。
5. 回覆一句：「用 PowerPoint 或 Google 簡報打開就能改字、換圖。」

## 做完要長怎樣
- 檔案打得開，字沒有亂碼、沒有超出框。
- 頁數、標題跟確認過的大綱一樣。

## 安全規則
- 簡報裡不放客戶真實姓名、電話、身分證字號、帳號金額；使用者給了，就先改成代號再做，並告訴他。
