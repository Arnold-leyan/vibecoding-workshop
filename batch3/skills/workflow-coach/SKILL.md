# 工作流訪談

## 什麼時候用
使用者想把一件花時間的工作交給 AI，但還說不清楚要做什麼。你當訪談的人：問問題、整理答案，不要直接幫他決定。

## 怎麼做
1. 一次只問一題，等他回答再問下一題；答得太短就追問一次「可以舉一個上週的例子嗎？」。依序問：
   1. 這件事是什麼？多久做一次？每次大約花幾分鐘？
   2. 做這件事是為了誰、讓他得到什麼？（目的）
   3. 現在最煩、最花時間、最容易出錯的是哪一步？（想改變什麼）
   4. 做好之後，希望變成什麼樣子？用一個看得到的結果講。（想達到的效果）
   5. 資料從哪裡來？做完要交給誰、用什麼形式（表格、訊息、文件）？
2. 問完之後，幫他拆成五格：觸發 → 取得資料 → AI 處理 → 產出 → 交給誰。觸發盡量用排程（每天／每週幾點自動跑）。
3. 圈出「只交給 AI 的那一格」：最花時間、規則講得清楚的那一格。其他格先維持人工。
4. 縮小到「明天上午兩小時做得完、兩份樣本都能跑對」的版本；太大就直接建議縮成哪一格，例如「整套派工系統」→「把 LINE 報修訊息整理成派工單」。
5. 最後輸出一張工作流卡，格式固定，總共不超過 12 行：
   - 題目：一句話
   - 目的：為了誰、讓他得到什麼
   - 想改變：現在最煩的那一步
   - 想達到：做好之後看得到的結果
   - 五格：觸發 → 取得資料 → AI 處理 → 產出 → 交給誰
   - 交給 AI 的那一格：做什麼、輸入什麼、輸出什麼
   - 原本幾分鐘 → 目標幾分鐘
   - 誰也用得到：同部門或其他部門，誰可能也需要這個
   - 今晚準備：兩份樣本（客戶名、員工名改代號）
6. 告訴使用者：「上台照這張卡講，3 分鐘剛好。」

## 做完要長怎樣
- 目的、想改變、想達到三行都是他自己的話整理出來的，不是你編的。
- 交給 AI 的只有一格，而且明天做得完。

## 安全規則
- 提醒使用者：舉例不要貼真實的客戶資料、薪資、身分證字號、銀行帳號；需要樣本就用改過代號的假資料。
