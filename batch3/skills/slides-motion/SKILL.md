# 簡報・炫款（網頁動畫）

## 什麼時候用
使用者要上台發表、想讓人印象深刻：大字、黑白對比、一頁一個重點、換頁有動畫。

## 怎麼做
1. 問主題和大約幾頁（沒說就做 6 頁），先列大綱：每頁「一句大標＋最多一行小字」。使用者說好再做。
2. 做成一個 index.html（所有樣式和程式都寫在同一個檔案裡，不連外部檔案）：
   - 一頁一個重點，大標至少佔畫面一半寬；黑底白字和白底黑字交錯，只用一個強調色。
   - 換頁有過場：淡入、滑入、文字一行一行出現，三種輪流用，不要每頁都一樣。
   - 鍵盤 ←、→、空白鍵換頁；手機可以左右滑；右下角顯示頁碼；按 F 全螢幕。
   - 字體用系統內建的（Noto Sans TC、微軟正黑體），不連外部字型。
3. 自己先檢查一次：每頁字都在畫面內、沒有錯字、最後一頁有「謝謝」。
4. 有 GitHub 小幫手（github-helper）的話，照它的步驟放上網，給使用者公開網址；沒有就直接把 HTML 檔傳給他，說「用電腦瀏覽器打開，按 F 全螢幕」。

## 做完要長怎樣
- 手機和電腦都打得開，換頁順、動畫不卡。
- 一頁只有一個重點，遠遠看也看得清楚。

## 安全規則
- 放上網就是公開：客戶資料、個資、金鑰一律不放；有的話先停下來問使用者。
