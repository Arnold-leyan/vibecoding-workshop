# 小遊戲卡

## 什麼時候用
使用者要一個簡單好玩的網頁小遊戲，例如活動問答、景點介紹、教育訓練小測驗、尾牙小遊戲、新人認識公司。

## 怎麼做
1. 先問一次就好（使用者已經講了就跳過）：給誰玩、什麼主題、想要哪一種玩法。沒想法就推薦三種最穩的：
   - 問答：5–10 題選擇題，答完看分數
   - 配對：翻牌找出兩兩一組
   - 點擊：限時 30 秒，點到目標就得分
   動作類（跑酷、射擊）在手機上容易卡，除非使用者堅持，不然先不做。
2. 用三句話跟使用者確認：怎麼玩、怎麼算分、怎樣算結束。使用者說好再做。
3. 做成一個 game.html（所有樣式、程式、圖示都寫在同一個檔案裡，不連外部檔案、不放音樂檔）：
   - 手機直式也能玩：按鈕夠大、字夠大，不用放大就點得到。
   - 一開始有「開始」畫面寫一句玩法，結束有分數和「再玩一次」。
   - 答對、答錯要有明顯的回饋（顏色或小動畫）；問答題答完顯示一句解釋。
   - 題目、文字放在檔案最上面的一個清單裡，之後要改題目只改那裡。
4. 自己先檢查一次：從開始玩到結束一輪，沒有卡住、沒有錯字、分數算得對。
5. 把 game.html 傳給使用者，說「用手機或電腦點開就能玩」。手機打不開，請他用電腦瀏覽器開。
6. 問他要不要調整：太難、太簡單、加題目、換顏色。只改他說的那一點。

## 做完要長怎樣
- 點開就能玩，不用安裝、不用登入、不用網路以外的東西。
- 一輪 1–2 分鐘玩得完，結束有分數。

## 安全規則
- 題目和內容不放客戶真實姓名、電話、身分證字號、帳號金額；使用者給了，就先改成代號。
- 不用別人的角色、商標、音樂、圖片；需要圖就用 emoji 或自己畫的簡單圖形。
