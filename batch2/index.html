③ AI Agent 基礎知識

  • 聊天 AI 和 Agent 差在哪：Agent 會自己拆步驟、動手做、做完回報
  • 剛才串好的龍蝦就是一個 Agent：它能做什麼、不能做什麼
  • 怎麼跟 Agent 講話：先講結果、講清楚怎樣算做完、卡住換句話說、一定自己驗
  • 資安三條：客戶資料不貼、金鑰不進對話、今天只連測試帳號
