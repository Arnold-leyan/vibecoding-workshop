Install · 1 / 8Windows

交給 Claude 安裝

在 Claude Desktop 的 Code 分頁開新對話，貼上這段：

請幫我在這台 Windows 電腦安裝 OpenClaw： 1. 用官方安裝腳本，並跳過設定精靈： & ([scriptblock]::Create((iwr -useb https://openclaw.ai/install.ps1))) -NoOnboard 2. 裝好後執行 openclaw --version 確認 3. 遇到錯誤自己排除，每一步用一句話告訴我在做什麼

它問「允許嗎？」按允許。跳出 Windows 的系統管理員視窗，按「是」。

你應該看到回報 OpenClaw 2026.9.8 之類的版本號。
錄製時 Claude 發現 iwr | iex 這種寫法會讓腳本參數驗證報錯，所以改用 scriptblock 寫法，提示詞已經直接寫成那個版本。電腦上的 Node.js 太舊時，它會用 winget 自動升級，期間會跳系統管理員授權。Mac 的同學把「Windows」改成「Mac」，Claude 會自己換成 Mac 的指令。

Install · 2 / 8Windows

開一個新的 PowerShell

按⊞ Win，輸入 PowerShell，按Enter一定要開新的，剛裝好的指令才找得到

PS>openclaw onboard --install-daemon

出現龍蝦圖案，選 Quick start (recommended)，按Enter。

--install-daemon 會把龍蝦裝成背景服務，電腦開機它就在。Claude 最後建議的指令可能只寫 openclaw onboard，請以這頁為準。上下鍵移動，Enter 確認。

Install · 4 / 8Telegram 電腦版

在 Telegram 建一個 bot

  1. 搜尋 @BotFather，打開對話
  2. 傳 /newbot
  3. 取名稱例：黎明小龍蝦，中文可以
  4. 取帳號，結尾一定要是 bot例：liming_lobster_bot
  5. 複製紅框裡那一長串 token

token 就是這個 bot 的鑰匙。不貼進 AI 對話，不傳給別人。

設定精靈先停在原地不用關，切到 Telegram 建 bot。截圖裡的 token 已經打上馬賽克。帳號名稱被用過時 BotFather 會要你換一個。
